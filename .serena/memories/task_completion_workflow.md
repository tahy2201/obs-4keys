# タスク完了時の作業フロー 🎯

## 必須チェック項目

### 1. コード品質
```bash
bun run lint                  # Next.js リント実行
```

### 2. ビルド確認  
```bash
bun run build                 # プロダクションビルド確認
```

### 3. データベース関連作業がある場合
```bash
bunx prisma generate          # Prisma クライアント再生成
bunx prisma migrate dev       # 必要に応じてマイグレーション
```

### 4. スクリプト関連作業がある場合
```bash
bun run build:scripts         # TypeScript スクリプトビルド
```

## 推奨フロー
1. コード変更
2. リント実行
3. ビルド確認
4. (必要に応じて) データベース作業
5. (必要に応じて) スクリプトビルド
6. 動作確認

## 注意事項
- Biome が自動フォーマットを行うため、手動フォーマットは不要
- strict モードが有効なため、型エラーに注意
- 120文字行幅制限を遵守
